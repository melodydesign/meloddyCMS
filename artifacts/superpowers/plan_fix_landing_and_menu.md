# План восстановления лендинга и фикса мобильного меню

## 1. Проблема: Мобильное меню на ПК (Дашборд)
- **Причина:** В файле `public/js/theme.js` мобильный заголовок инжектится с жестко заданным инлайн-стилем `display: flex;`. Из-за этого он переопределяет CSS-правила из `style.css` и всегда показывается, даже на десктопе (1920px).
- **Решение:**
  - Отредактировать `public/js/theme.js` (строка 62). Убрать `display: flex;` из `mobileHeader.style.cssText`.
  - Заменить жесткие инлайн-стили на динамическое добавление тега `<style>` с медиа-запросом, как это уже сделано в `theme-v2.js`: `.mobile-header { display: none !important; } @media (max-width: 768px) { .mobile-header { display: flex !important; } }`.
  - Убрать жесткий отступ `mainContent.style.paddingTop = '80px';` для ПК. Сделать так, чтобы он применялся только на мобилках.

## 2. Проблема: Отсутствие лендинга
- **Причина:** Файл `index.html` был перезатерт временным редиректом. Исходный код лендинга утерян из-за обрезания логов.
- **Решение:** 
  - Написать новый чистый код лендинга в `public/index.html`.
  - Структура будет использовать сохраненные стили из `public/css/landing.css`: `.land-header`, `.land-hero`, `.land-text-gradient`, `.land-hero-actions`, `.land-btn`.
  - Лендинг будет выглядеть премиально, стильно и точно так же, как в оригинале (заголовок "Российская система управления сайтами", кнопки регистрации/входа, мокап интерфейса).

## 3. Развертывание
- Запустить `scratch/deploy_changes.ps1`, чтобы загрузить обновленный `index.html` и `theme.js` на сервер.
- Сбросить кэш PM2 для надежности.

## Верификация
1. Открыть `meloddy-crm.ru` — должен загрузиться красивый лендинг, а не голый текст или редирект.
2. Перейти в Дашборд — мобильного меню `≡` больше не должно быть на ПК-версии (ширина экрана > 768px). Заголовок "Дашборд" не должен перекрываться шапкой.
