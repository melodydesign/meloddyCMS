# Мини-план деплоя изменений

## 1. Цель
Запустить скрипт деплоя для синхронизации файлов проекта с удаленным сервером и перезапустить PM2, чтобы пользователь мог убедиться в работоспособности системы после удаления временных файлов.

## 2. Шаги реализации
* **Шаг 1. Запуск деплоя**: Выполнить скрипт `deploy.py` с помощью Python (или `deploy_changes.ps1` через PowerShell, если Python-библиотека `paramiko` не установлена). Мы начнем с попытки запустить `python deploy.py`.
* **Шаг 2. Проверка вывода**: Убедиться, что файлы успешно загружены по SFTP и PM2 на сервере успешно перезапущен.

## 3. Верификация
* Проверка статус-кода выполнения скрипта (успешно).
* Чтение логов вывода команды перезапуска PM2.
