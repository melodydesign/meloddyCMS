# Brainstorm & Plan: "WOW" Hero Section & Full-Width Layout

## Goal
Сделать первый блок (Hero) максимально впечатляющим ("WOW"-эффект), использовать продвинутые CSS-эффекты и перевести вёрстку на всю ширину экрана с отступами 40px по краям.

## Constraints & Requirements
- Отступы по краям строго 40px (`padding: 0 40px`).
- Вёрстка на всю ширину (`max-width: 100%` вместо `1200px`).
- Никаких тяжелых библиотек (Three.js и т.д.), используем мощный CSS + ванильный JS для интерактивности.

## Ideas for "WOW" Effect
1. **Full-Width Layout**: Убираем ограничение `max-width: 1200px` для `.land-container`. Заменяем на `width: 100%; padding: 0 40px;`.
2. **Typography**: Огромный, акцентный заголовок с анимированным градиентом, который переливается (background-position animation).
3. **Complex Background**: Анимированная сетка с перспективой (3D grid) уходящая вдаль, плюс движущиеся неоновые сферы (blur `150px`).
4. **Interactive Dashboard**: Плавающий интерфейс CMS (SVG), который слегка поворачивается за курсором мыши (3D Parallax effect на чистом JS - `mousemove`).
5. **Glassmorphism Header**: Хедер на всю ширину (с 40px отступами), парящий над контентом с сильным размытием.

## Step-by-Step Plan
1. **Обновить `landing.css`**:
   - Изменить `.land-container` на 100% ширину с padding 40px.
   - Добавить сложный анимированный фон для `.land-hero` (3D сетка + glowing orbs).
   - Увеличить шрифты заголовка `clamp(3rem, 6vw, 6rem)`.
   - Добавить класс для 3D tilt-эффекта и градиентных свечений.
2. **Обновить `index.html`**:
   - Изменить структуру Hero (сделать текст крупнее, по центру или слева с огромным SVG справа).
   - Добавить JS-скрипт для отслеживания мыши (Mouse Move 3D Parallax) для интерактивности главного визуала.
3. **Деплой на сервер**:
   - Запустить `deploy_script.js` для быстрой заливки на 195.209.214.15.

## Verification
- Открыть `localhost:3000` (или сервер).

- Проверить 3D эффект при движении мышкой.
- Проверить адаптивность (на мобильных отступы уменьшаются до 20px).
