# План обновления раздела Для Разработчиков

## Цель
Убрать из документации внутренние детали платформы (Node.js, PM2, JSON, Nginx, API) и сфокусироваться на прикладных задачах разработчика: как интегрировать верстку, как работает функционал, как размечать данные.

## Шаги
1. Изменить оглавление (TOC) вкладки «Для разработчиков».
2. Написать новые секции:
   - **Интеграция верстки:** Как правильно запаковать ZIP-архив с сайтом и загрузить в систему.
   - **Разметка (Посадка на CMS):** Полный список `data-editable`, `data-img-editable`, `data-bg-editable` и как их использовать.
   - **Настройка форм (Лиды):** Как связать обычные HTML-формы с Telegram-ботом CMS.
   - **Шаблонизация:** Как создать шаблон (template.json) для быстрого развертывания типовых проектов.
3. Очистить файл `docs.html` от старых секций (Архитектура, Routing, Деплой, API).
4. Задеплоить изменения на сервер.

## Проверка
После внедрения проверим, что в разделе разработчика нет упоминаний внутренней архитектуры, а есть только полезные инструкции по посадке сайтов.
