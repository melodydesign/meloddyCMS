# План реализации: Детальная статистика и действия в Панели Админа (Фаза 3.1)

## 1. Цель
Расширить Панель Супер-Админа, добавив возможность глубокого просмотра и управления каждым пользователем (клиентом и разработчиком).
Администратор сможет видеть детальную активность, статус тарифа, сроки, а также совершать действия с аккаунтом.

## 2. Ограничения и риски
- Безопасность: Все детальные эндпоинты должны быть защищены проверкой роли `admin`.
- Парсинг логов: Активность нужно собирать из общего `history.json`, фильтруя по `userId`.

## 3. Пошаговый план

### Шаг 1: Backend API для деталей пользователя
- В `src/routes/admin.js` добавить эндпоинт `GET /api/admin/users/:id/details`.
- Эндпоинт должен возвращать:
  - Информацию о тарифе пользователя и датах (когда выдан PRO).
  - Список сайтов, принадлежащих этому пользователю (из `sites.json`).
  - Последнюю активность пользователя (отфильтрованную по его `userId` из файла `logs/history.json`).

### Шаг 2: Frontend UI - Модальное окно деталей
- В `public/admin.html` добавить разметку модального окна `adminUserModal` (схожего по дизайну с `siteMenuModal`).
- В модальном окне разместить блоки:
  - **Основная информация**: Роль, Тариф, Дата регистрации (если есть).
  - **Статистика и Активность**: Последние 10-20 действий пользователя на платформе.
  - **Сайты пользователя**: Быстрый список сайтов.
  - **Панель управления**: Кнопки "Изменить тариф (Выдать PRO)", "Удалить пользователя" (пока можно сделать их просто визуально с заглушками или реализовать базовое изменение тарифа).

### Шаг 3: Frontend логика
- В `public/js/admin.js` добавить колонку "Действия" с кнопкой "Подробнее" в таблицу пользователей.
- При клике на "Подробнее" делать запрос на сервер, получать детали и открывать модальное окно.

### Шаг 4: Тестирование
- Убедиться, что клик по "admin" или "client1" открывает модалку и корректно выводит историю изменений файлов и список их сайтов.

## Вопросы к Владельцу
- Нужно ли прямо сейчас реализовывать кнопки *редактирования* пользователя (например, Вручную выдать PRO-тариф, заблокировать), или пока достаточно глубокого *просмотра* (активность, сайты, тариф)?
