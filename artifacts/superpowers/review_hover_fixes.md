# Отчет о ревью исправления ховеров и меню

Была проведена проверка внесенных изменений для исправления отображения кнопок и меню на ховере.

## Список найденных замечаний по критичности

### Blocker
*Нет* (синтаксис JS и CSS корректен, PM2 успешно перезапустился).

### Major
*Нет*.

### Minor
* **Зависимость от кэша**: Поскольку стили `style.css` и JS `dashboard_v2.js` обновлены, пользователю может потребоваться принудительно обновить страницу (`Ctrl + F5`) для применения новых правил отображения.

### Nit
*Нет*.

## Результаты проверки
1. Из глобальных селекторов кнопок в `style.css` полностью убран тег `button`. Все основные стили перенесены на класс `.btn`. Это исправило ховеры неактивных табов, кнопки трех точек и пунктов выпадающего меню.
2. Карточкам проектов `.hero-card` и `.site-card` добавлено позиционирование `position: relative` и динамический класс `.active-dropdown` с `z-index: 50`, что полностью предотвращает обрезание плашки меню следующими карточками.
3. Логика открытия выпадающего меню исправлена: состояние теперь считывается через `getComputedStyle`, что убрало баг "первого клика".
4. Изменения успешно залиты на сервер.
