# План: Деплой на удаленный сервер

Так как стандартные команды `ssh/scp` в Windows требуют интерактивного ввода пароля, я напишу небольшой локальный скрипт на Node.js для подключения к вашему серверу (195.209.214.15) и автоматического деплоя.

## Шаги:
1. **Подготовка**: Создать временный скрипт для подключения по SSH, чтобы найти папку с проектом на сервере (обычно `/var/www/meloddyCMS` или в домашней директории).
2. **Загрузка файлов**: Загрузить на сервер все файлы, которые мы изменили:
   - `public/dashboard.html`
   - `public/js/dashboard.js`
   - `public/js/dashboard_v2.js`
   - `src/services/telegram.js`
   - `src/routes/sites.js`
3. **Перезапуск**: Выполнить команду перезапуска процесса на сервере (скорее всего `pm2 restart all` или перезапуск системной службы).
4. **Удаление следов**: Удалить временные скрипты для деплоя локально.
