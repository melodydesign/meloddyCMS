# План исправления ховеров кнопок и выпадающего меню meloddyCMS

Исправление багов с исчезновением текста кнопок/меню на ховере в светлой теме и обрезанием выпадающего меню карточек проектов.

## Шаги реализации

1. **Модификация [style.css](file:///c:/Users/9/Desktop/meloddyCMS/public/css/style.css)**:
   - Удалить селектор `button` из глобальных стилей кнопок (строки 411, 429, 435, 439, 443, 452). Оставить стилизацию только для класса `.btn`, чтобы обычные кнопки (табы, иконки, элементы меню) не получали принудительный синий фон и белый текст на ховере.
   - Добавить `position: relative` для `.hero-card` и `.site-card` для правильного позиционирования абсолютных элементов внутри них.
   - Добавить класс `.active-dropdown` для `.hero-card` и `.site-card` со стилями `z-index: 50 !important` и `position: relative !important`, чтобы карточка с открытым меню всегда отображалась поверх соседних элементов.
   - Задать стиль для `.site-action-btn` (кнопка трех точек) для правильного отображения цвета иконок в темной и светлой темах.

2. **Модификация [dashboard_v2.js](file:///c:/Users/9/Desktop/meloddyCMS/public/js/dashboard_v2.js)**:
   - Исправить баг первого клика по трем точкам (сравнивать фактическое состояние отображения меню через `window.getComputedStyle`).
   - При открытии выпадающего меню добавлять класс `.active-dropdown` на родительский элемент `.hero-card`.
   - При закрытии меню или клике на другую карточку убирать класс `.active-dropdown`.

3. **Запуск деплоя**:
   - Выполнить `python deploy.py` для обновления файлов на удаленном сервере и перезапуска PM2.

## Верификация
- В светлой теме навести курсор на вкладки настроек ("Профиль", "Внешний вид") — текст должен оставаться читаемым, без синего фона и сдвигов.
- Нажать на три точки на карточке проекта с первого клика — меню должно открыться.
- Убедиться, что выпадающее меню отображается поверх следующей карточки (не перекрывается и не обрезается).
- Навести курсор на пункты выпадающего меню ("Редактировать", "Файлы") — текст должен оставаться читаемым и контрастным.
