# План доработки (Часть 2)

Выявил все недочеты по скриншотам. 

## 1. Исправление верстки (Дашборд)
- **Обрезанные края вкладок:** Уберу обрезание (overflow) и поправлю отступы у кнопок. 
- **Расположение "друг за другом":** Перестану принудительно растягивать вкладки на всю ширину. Они будут идти аккуратными чипсами друг за другом (как теги).
- **Иконки редактирования/удаления:** Перенесу их красивее (например, при наведении они будут аккуратно появляться сбоку или в углу карточки).
- **Пустая плашка "Нет проектов":** Растяну на 100% ширины контейнера.

## 2. Устранение "моргания" и глобальное скрытие элементов
- **Проблема:** База знаний и промо-блок видны в HTML, и только после загрузки JS они скрываются (поэтому вы видите их долю секунды, а на других страницах они вообще не пропадали).
- **Решение:** Я скрою их в HTML по умолчанию (`display: none`), и буду **показывать** только для обычных клиентов. Это уберет моргание и решит проблему на всех страницах (Профиль, Настройки, Админка).

## 3. Редизайн Профиля и Админки (Glassmorphism)
- **Профиль:** Карточки "Настройки профиля" и "Смена пароля" получат такой же дорогой "стеклянный" вид (`stat-card-glass`), как на дашборде.
- **Админка:** Таблицы пользователей и сайтов переведу в стеклянный дизайн. Уберу зависшую надпись "Загрузка...".

## 4. Новая функция: Отключение сайтов
- В админ-панели (вкладка "Все сайты") добавлю новую кнопку/тумблер **"Выключить сайт" / "Включить сайт"**.
- Добавлю API маршрут (`/api/admin/sites/:id/toggle-status`), который будет менять статус сайта. 
- Выключенный сайт не будет доступен в интернете (или будет отдавать заглушку).
