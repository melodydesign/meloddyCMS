# Редизайн дашборда и сайдбара meloddyCMS под новый стиль

Этот документ содержит брейншторм, требования, риски, критерии приемки и пошаговый план реализации редизайна панели управления (дашборда и левого сайдбара) согласно спецификации из [UI_KIT.md](file:///c:/Users/9/Desktop/meloddyCMS/UI_KIT.md).

---

## 1. Брейншторм (Brainstorm)

### Цель (Goal)
Полный редизайн страницы дашборда (`public/dashboard.html`) и левого сайдбара (`aside.sidebar`) под новый современный стиль из [UI_KIT.md](file:///c:/Users/9/Desktop/meloddyCMS/UI_KIT.md). Интерфейс должен выглядеть премиально, иметь плавные микро-анимации, стеклянные карточки (Glassmorphism), правильные отступы и шрифты (Inter), а также поддерживать светлую и темную темы с обновленными токенами.

### Ограничения (Constraints)
- **Сохранение функционала:** Все существующие JS-обработчики, AJAX-запросы, динамический рендеринг проектов, шаблонов, активности и заявок в `public/js/dashboard_v2.js` должны продолжать корректно работать.
- **Динамический контент:** Поскольку HTML-код карточек проектов, активности, шаблонов и заявок генерируется динамически в JS, стили и новые классы должны быть внедрены как в CSS (`public/css/style.css`), так и в динамический рендеринг в JS (`public/js/dashboard_v2.js`).
- **Сетка и Отступы:** Использование сетки Bento Grid для карточек или аккуратного флекс-интерфейса, скругленные кнопки (pill-shaped), стеклянные карточки с размытием (`backdrop-filter`).
- **Язык общения и планов:** Русский язык.

### Риски (Risks)
- **Нарушение верстки при динамическом рендеринге:** Если изменить структуру классов в CSS, динамически создаваемые в `dashboard_v2.js` элементы могут потерять стилизацию. Мы должны скоординировать CSS и JS изменения.
- **Кэширование браузером:** Изменения в CSS/JS могут не сразу примениться в браузере пользователя (потребуется сброс кэша или версионирование).
- **Сломанные обработчики кликов:** В `dashboard_v2.js` навешиваются обработчики событий на кнопки действий сайтов, табы клиентов и модальные окна. Мы должны аккуратно обновить разметку, сохранив селекторы (например, `.client-name-btn`, `.site-actions-wrapper`, `.site-action-btn`, `.site-dropdown-menu`, `.site-menu-item`).

### Критерии приемки (Acceptance Criteria)
1. **Сайдбар:**
   - Премиальный дизайн с размытием или чистыми цветами из UI Kit.
   - Плавное раскрытие сайдбара при наведении (сохранение функционала, но в улучшенном визуальном исполнении).
   - Активный элемент меню подсвечивается градиентом или акцентным синим цветом (`--accent-blue` / `#2563EB`).
   - Иконки меню имеют правильные размеры, плавные ховер-эффекты.
2. **Дашборд (Обзор проектов):**
   - Шрифты заменены на **Inter** с правильной иерахией.
   - Блоки статистики (`Stats Grid`) оформлены как стеклянные карточки с мягкой тенью и скруглением `radius-lg` / `24px` (согласно UI-Kit).
   - Кнопки («Загрузить сайт», «Корзина», кнопки в карточках проектов) переделаны в скругленные (pill-shaped, `border-radius: 99px`), с микро-анимацией сдвига вверх на 2px при наведении и мягким свечением.
   - Карточки проектов в списке (`sitesContainer`) оформлены как `.feature-card` с эффектом Glassmorphism (`backdrop-filter: blur(20px)`), границами `--border-color` и скруглением 24px.
   - Иконка проекта (`.feature-icon`) анимируется при наведении на карточку (поворот на 3 градуса, увеличение на 15%).
   - Формы и поля ввода (например, в модальных окнах или настройках) оформлены по стилю: светло-серый фон `#F4F4F5` (светлая тема) / темно-серый `#1A1A1A` (темная тема), скругление 12px, паддинг 16px 20px, при фокусе — синяя рамка и свечение `box-shadow: 0 0 0 4px rgba(37, 99, 235, 0.2)`.
3. **Цветовая палитра:**
   - Светлая тема использует `--bg-main: #FFFFFF`, `--bg-secondary: #F9FAFB`, `--text-primary: #09090B`, `--text-muted: #71717A`, `--border-color: #E4E4E7`, `--accent-blue: #2563EB`, `--success: #10B981`.
   - Темная тема использует `--bg-body: #0D0D0D`, границы `#222222` / `#333333`, темный фон для карточек.
   - Поддерживаются парящие фоновые сферы с размытием (`.hero-sphere`) для придания глубины.

## 2. Пошаговый план реализации (Implementation Plan)

### Шаг 1: Обновление цветовых токенов и глобальных стилей в CSS
- Изменить переменные в `:root` (темная тема) и `[data-theme="light"]` (светлая тема) в `public/css/style.css` под новые значения из UI Kit.
- Установить шрифт по умолчанию: `'Inter', sans-serif` для всех элементов.
- Добавить CSS-классы для парящих сфер `.hero-sphere` и градиентного текста `.text-gradient`.

### Шаг 2: Редизайн левого сайдбара (`.sidebar`)
- Обновить стили сайдбара в `public/css/style.css`. Сделать его стеклянным (Glassmorphism) с `backdrop-filter: blur(20px)` и тонкой границей справа.
- Стилизовать логотип: применить сближенный межбуквенный интервал `letter-spacing: -0.02em` и градиентную подсветку.
- Обновить стили `.nav-item`: сделать ховер-эффекты более плавными, добавить подсветку активного пункта с помощью фиолетово-синего градиента или синего акцента, а также скругление по UI-Kit.

### Шаг 3: Редизайн элементов дашборда и статистики
- Переработать `.stats-card` (карточки статистики): скругление `24px`, стеклянный фон, мягкая тень, микро-анимация при наведении.
- Обновить вкладки переключения клиентов / категорий (`.client-tab-item`, `.dev-tab`): сделать их более изящными, с красивой синей или градиентной линией снизу для активных элементов.

### Шаг 4: Обновление динамического JS-рендеринга карточек проектов и активности
- Отредактировать функции в `public/js/dashboard_v2.js` (`renderClientSites`, `loadSites`, `loadRequests`, `loadTemplates`):
  - Добавить стеклянные карточки `.feature-card` (или назначить эти стили на `.hero-card`).
  - Применить скругление `24px` для карточек.
  - Стилизовать иконку проекта как `.feature-icon` (размер 48x48, скругление 12px, поворот и масштаб при наведении на родительскую карточку).
  - Сделать статус-индикаторы сайтов («Онлайн», «Оффлайн», «Черновик») более эстетичными (мягкий фон, мелкий шрифт).
  - Оформить меню действий проекта (три точки) в более современном виде.

### Шаг 5: Редизайн кнопок, форм и инпутов
- В `public/css/style.css` обновить стили `.btn`, `.btn-primary`, `.btn-accent`, `.btn-outline` под требования UI Kit:
  - Скругление `99px` (pill-shaped) для кнопок.
  - Анимация при наведении: `transform: translateY(-2px)`, мягкая тень / неоновое свечение.
  - Обновить стили полей ввода (input, textarea, select): фон, границы, фокус со свечением.

### Шаг 6: Редизайн страницы управления проектом (`siteManageContainer`)
- Обновить внутреннюю верстку `siteManageContainer` в `public/dashboard.html` и стили в `style.css`:
  - Кнопка «Назад» и верхняя панель.
  - Вкладки управления (Настройки, Обзор, SEO, Доступ, Опасная зона).
  - Настройки и формы ввода данных.
  - Графики (Chart.js) — настроить цвета графиков под новую палитру (синий/фиолетовый акценты вместо старых цветов).
