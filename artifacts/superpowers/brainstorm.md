## Goal
Уточнить адаптивную верстку для мобильных устройств:
1. Задать размер `h1` равным `2rem !important` на мобильных экранах.
2. Убрать принудительное растягивание кнопок `.hero-cta .btn` на всю ширину (убрать `width: 100% !important`). Кнопки должны располагаться вертикально по центру со своей естественной шириной.
3. Разработать отдельный, оптимизированный под мобильные блок преимуществ вместо сложного `.monster-ide`, который скрывается на мобильных.
4. Оптимизировать блок тарифов (`.pricing-card`) под мобильные экраны (уменьшить паддинги, размер шрифта цены).

## Constraints
- Все планы и общение на русском языке.
- IT-синий цвет темы сохранен.
- Полное соответствие макетам и пожеланиям пользователя по размерам шрифтов.
- Мобильная версия блока преимуществ должна содержать все 8 преимуществ (для владельцев и для разработчиков) в виде аккуратного списка карточек.

## Known context
- Файл `index.html` содержит разметку `.monster-ide` в секции `#benefits`.
- Стили для мобильного медиа-запроса `max-width: 768px` прописаны в конце `landing.css`.
- Выкатка через `.\deploy_changes.ps1`.

## Risks
1. **Дублирование контента:** Использование двух разных блоков (один для десктопа, другой для мобильного) увеличивает размер HTML.
   *Решение:* Разметка преимуществ текстовая и лаконичная, поэтому дублирование не повлияет на производительность, зато обеспечит идеальный UX на смартфонах.
2. **Центрирование кнопок Hero:** Если убрать `width: 100%`, кнопки могут прижаться к левому краю, если не задано центрирование во флекс-контейнере.
   *Решение:* Задать для `.hero-cta` на мобильных `flex-direction: column` и `align-items: center` для идеального центрирования кнопок.

## Options (2–4)
- **Вариант 1:** Попытаться переверстать `.monster-ide` так, чтобы он не ломался на мобильных. (Не рекомендуется, так как симулировать сложный интерфейс IDE на маленьком экране смартфона неудобно для пользователя).
- **Вариант 2 (Рекомендуемый):** Скрыть `.monster-ide` на экранах менее 768px и взамен вывести чистый, структурированный блок преимуществ `.mobile-benefits-container`. Оптимизировать шрифты (`h1` -> `2rem`), кнопки Hero и карточку тарифов.

## Recommendation
Использовать **Вариант 2**. Это полностью решит проблему перегруженности мобильной версии и сделает сайт максимально аккуратным.

## Acceptance criteria
1. На экранах до 768px заголовок `h1` имеет размер `2rem`.
2. Кнопки в первом блоке расположены по вертикали, выровнены по центру и имеют автоматическую ширину (не растянуты на 100%).
3. Блок `.monster-ide` скрыт на мобильных. Вместо него выводится красивый вертикальный список карточек преимуществ, разделенный на блоки «Для владельца сайта» и «Для разработчика».
4. Карточка тарифов на мобильных имеет уменьшенные внутренние отступы (32px сверху/снизу, 24px по бокам), чтобы контент не зажимался. Кнопка тарифа растягивается на 100% для удобства нажатия пальцем.
5. Деплой проходит успешно.
