# Brainstorm: Создание интернет-магазина

## Goal (Цель)
Создать простой интернет-магазин в папке `site/shop`, привязать его к CMS (id владельца 3 - клиент, разработчик - dev). Заполнить 10 товарами и предоставить инструкцию по связыванию товаров из CMS с клиентским сайтом.

## Constraints (Ограничения)
- Взаимодействие и документация на русском языке.
- Изменения должны быть внесены напрямую в файлы `data/sites.json`, `data/users.json` и `data/products/shop.json`.
- Магазин должен быть простым (HTML/CSS/JS) и использовать публичный API CMS для отображения товаров (`/api/commerce/shop/products`).

## Risks (Риски)
- Нарушение структуры JSON в файлах БД (sites.json, users.json).
- Ошибки CORS или проблемы с путями, если использовать неправильный API эндпоинт.

## Options (Варианты решения)
1. Сделать `shop` как статический сайт внутри `site/shop/index.html`.
2. Настроить API-запросы через `fetch` к `/api/commerce/shop/products` с фронтенда для динамической загрузки 10 товаров, которые мы сгенерируем в `data/products/shop.json`.

## Recommendation
Выбрать Вариант 2, так как он демонстрирует динамическую связь сайта с CMS, как и просил пользователь.

## Acceptance Criteria (Критерии приемки)
- В `data/sites.json` добавлен сайт `shop` для `owner: 3`.
- В `data/users.json` у пользователя `client` добавлен `shop` в `sites`, а `developerCode` изменен на код разработчика `dev`.
- В `site/shop` есть рабочий `index.html` и `script.js`, которые подтягивают товары.
- Создан файл `data/products/shop.json` с 10 товарами.
- Предоставлена инструкция по связке CMS и сайта.
