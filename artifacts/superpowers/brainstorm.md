# Мозговой штурм: Премиальный магазин кроссовок meloddyCMS

## 1. Цели и задачи
* **Импорт 25 товаров с sneakerbox.ru**: 
  - Написать Python-скрипт `scratch/import_sneakers.py`, который скачает каталог мужских кроссовок с `https://www.sneakerbox.ru/ru/men` (страницы 1 и 2).
  - Собрать для каждого товара: название, оригинальную цену, цену со скидкой, описание, доступные размеры, доступные цвета с HEX-кодами и все изображения.
  - Локально сохранить изображения в `site/shop/images/` с хэшированными именами (для полной имитации ручного ввода).
  - Очистить старые товары и сохранить новые в `data/products/shop.json` в формате CMS с заполнением полей `variants`, `colorHex`, `colorName`, `badge`, а также случайных габаритов доставки (`length`, `width`, `height`, `weight`).
  - Создать категории в `data/categories/shop.json`.
* **Редизайн витрины и детальной карточки**:
  - Создать премиальный, минималистичный дизайн интернет-магазина в стиле Nike Lab / Zara / Apple.
  - Добавить эффекты парения (3D float/tilt) для Hero-картинки, градиентные заглавия, размытия.
  - Переделать корзину в выезжающий справа Drawer (вместо модалки по центру).
  - Карточку товара (Quick View) сделать сложной: левая колонка — галерея с переключением миниатюр и эффектом лупы (zoom) при ховере, правая — красивый выбор размеров, цветов, детальное описание и вкладки (Табы: Описание, Характеристики, Доставка).
* **Интеграция с визуальным редактором**:
  - Обвесить все статические секции в `site/shop/index.html` атрибутом `data-block-id` (header, hero, catalog, about, footer).
  - Обвесить заголовки, тексты, кнопки и ссылки атрибутами `data-editable="..."`, а картинки — `data-img-editable="..."` для полного редактирования в CMS.

## 2. Формат данных в `shop.json`
Каждый товар будет иметь следующую структуру:
```json
{
  "id": "prod_random",
  "name": "Название модели",
  "slug": "slug-name-1234",
  "sku": "артикул",
  "price": 11499,
  "oldPrice": 17999,
  "stock": 10,
  "status": "active",
  "categories": ["cat_brand", "cat_shoes"],
  "tags": [],
  "description": "Детальное описание с sneakerbox",
  "images": [
    "images/downloaded_hash1.jpg",
    "images/downloaded_hash2.jpg"
  ],
  "customFields": {
    "Brand": "Reebok",
    "Модель": "Nano X5"
  },
  "colorHex": "#FFA500",
  "colorName": "Оранжевый",
  "length": 32,
  "width": 20,
  "height": 12,
  "weight": 0.8,
  "variants": [
    { "name": "Размер", "value": "41", "image": "" },
    { "name": "Цвет", "value": "Оранжевый", "image": "images/downloaded_hash1.jpg" }
  ],
  "type": "product",
  "createdAt": "2026-06-12T..."
}
```

## 3. Риски и ограничения
* **Объем скачиваемых картинок**: 25 товаров по 4-5 картинок на каждый — это ~100-125 картинок. Загрузка должна происходить асинхронно или последовательно с таймаутами, чтобы не перегрузить сеть и не получить блокировку от sneakerbox (FLO CDN). Изображения должны сжиматься или ограничиваться по размеру.
* **Связывание скриптов**: Мы должны обновить `site/shop/script.js` and `site/shop/style.css` так, чтобы не сломать логику AJAX-запросов к API CMS (`/api/commerce/shop/public/products` и `/api/commerce/shop/public/categories`), пагинации и поиска.

## 4. Критерии приемки
1. База данных содержит ровно 25-26 реальных кроссовок с sneakerbox.ru с реальными ценами, скидками, описаниями и фото.
2. Картинки товаров лежат локально в `site/shop/images/` и отображаются корректно.
3. Витрина выглядит дорого (минималистичный стиль, стеклянная шапка, Bento-подобные или изящные карточки, плавные анимации hover).
4. Корзина выезжает справа, работает удаление и изменение количества, оформление заказа отправляет запрос.
5. Карточка товара имеет галерею миниатюр, переключатель размеров, таб-панель характеристик и габаритов.
6. Весь статический контент витрины доступен для редактирования из визуального редактора meloddyCMS.
