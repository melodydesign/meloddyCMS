# План: Интеграция ИИ-промпта подготовки кода и обновление главной страницы

## Цель
1. На главной странице (`public/index.html`) заменить карточку преимущества «Гибкая структура» на преимущество «ИИ-кодогенераторы» (описав совместимость с ИИ-конструкторами кода в профессиональном стиле).
2. Создать специализированный системный промпт для LLM/ИИ, который автоматизирует подготовку любого статического сайта (включая сгенерированные в визуальных редакторах кода вроде VibeCode) под формат meloddyCMS.
3. Сохранить этот промпт в корне репозитория в файле `AI_PREPARATION_PROMPT.md` и добавить соответствующий раздел в Базу Знаний `public/kb.html` (вкладка для разработчиков, раздел №11).

### 2. Создание файла с ИИ-промптом
#### [NEW] `AI_PREPARATION_PROMPT.md`
Написать детальный промпт на русском языке для ИИ (ChatGPT/Claude/Gemini), который:
- Распределяет файлы по нужной структуре папок (`/css`, `/js`, `/img`, `index.html` в корне).
- Исправляет все пути в HTML на относительные от корня (например, `/css/style.css`).
- Автоматически находит все редактируемые тексты и добавляет к ним уникальные `data-editable="ключ"`.
- Находит изображения и добавляет `data-img-editable="ключ"`.
- Находит формы, выставляет `action="/api/submit-form"` и `method="POST"`, а также добавляет читаемые `name="..."` для инпутов.

## План верификации

### Ручная проверка
1. Применить изменения и запустить `.\deploy_changes.ps1`.
2. Проверить главную страницу: вместо «Гибкая структура» должна отображаться карточка «ИИ-кодогенераторы».
3. Проверить страницу базы знаний `kb.html` во вкладке для разработчиков: должен появиться 11-й пункт в оглавлении и контенте, содержащий готовый промпт.
4. Открыть созданный файл `AI_PREPARATION_PROMPT.md` в репозитории и убедиться в правильности формулировок.
