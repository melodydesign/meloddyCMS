# План исправления скрипта деплоя `deploy.py`

Исправление ошибки `UnicodeEncodeError` при выводе результата перезапуска PM2 на Windows-системе.

## Шаги реализации
1. **Модификация `deploy.py`**:
   - Безопасно декодировать и выводить `stdout` и `stderr` PM2.
   - Использовать безопасный вывод строк с заменой непечатаемых/некодируемых символов в терминале.
2. **Запуск деплоя**:
   - Выполнить `python deploy.py` локально.
3. **Верификация**:
   - Убедиться, что скрипт завершается с кодом 0 и выводит лог перезапуска PM2 без ошибок кодировки.
