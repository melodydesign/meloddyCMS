# План исправлений (UI и Админка)

## 1. Brainstorm (Анализ)
- **Цель:** Исправить отображение для роли "Админ", поправить баги с кнопками в светлой теме, убрать лишнее свечение, заставить работать новые "вкладки" активных проектов, а также починить вкладку "Все сайты" в админ-панели.
- **Требования:**
  1. "База знаний" — скрыть в сайдбаре для админа.
  2. "Подписка" и "Тариф Beta" — скрыть для админа (в профиле и дашборде).
  3. "Привязка к разрабу" — не показывать для админа в списке пользователей (в Управлении платформой).
  4. "Все сайты" — админ должен видеть вообще все сайты системы в админке.
  5. Свечение при наведении — убрать градиентное свечение с кнопок (оставить только небольшое увеличение масштаба или смену цвета).
  6. Формы/Инпуты (с подчеркиванием) — сделать их более заметными (линия длиннее/толще).
  7. Вкладки (Активные проекты) — применить обещанный дизайн (цветные чипсы-вкладки), который не применился из-за ошибки кэша/замены строк.
  8. Светлая тема — исправить цвет текста при наведении на кнопки (чтобы текст не становился черным на фиолетовом фоне).

## 2. Пошаговый план
1. **CSS (`style.css`):**
   - Убрать `box-shadow: 0 0 20px...` из `.btn:hover`.
   - Проверить инпуты: добавить `border-bottom-width: 2px; padding: 16px 0;` чтобы подчеркивание было массивнее, как просит пользователь.
   - Убедиться, что `.btn:hover` получает `color: #ffffff !important;` для сохранения читаемости иконки и текста.
2. **HTML & JS (`dashboard.html`, `dashboard.js`):**
   - Скрыть "Базу знаний" (добавить id и `display: none` если `isAdmin`).
   - Скрыть `.sidebar-promo-card` для `isAdmin`.
   - Внедрить **рабочий** код для вкладок (через точный `replace` или DOM-манипуляцию), чтобы вкладки стали нормальными чипсами.
3. **Admin & Profile (`profile.html`, `admin.html`, `admin.js`):**
   - В `profile.html`: скрыть блоки с подпиской для админа.
   - В `admin.js`: проверить функцию загрузки всех сайтов. Скорее всего она падает или возвращает пустоту из-за бага на бекенде, нужно это проанализировать.
   - В `admin.js`: при рендере списка пользователей убрать "Код разработчика" для суперадмина.
4. **Верификация:**
   - Все изменения проверяются локально и затем деплоятся.
