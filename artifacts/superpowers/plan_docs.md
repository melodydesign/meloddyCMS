# План переработки дизайна Базы знаний

## Проблема
Текущий дизайн просто "всё увеличил" и растянул на 100% ширины, из-за чего строки текста стали слишком длинными, читать неудобно, а элементы выглядят громоздко и негармонично. Вкладки конфликтуют с глобальными стилями кнопок.

## Цель
Сделать стильный, аккуратный и читаемый интерфейс в духе meloddyCMS. Контейнер будет широким, но сама колонка с текстом будет иметь ограничение по ширине для комфортного чтения.

## Шаги реализации

1. **Сетка и Layout (Широко, но удобно)**
   - Изменим `.docs-page-container`: `max-width: 1440px`, отступы `2rem 4rem`.
   - В `.docs-layout` ограничим ширину контентной части (`.docs-content { max-width: 800px; }`), чтобы длина строк текста была оптимальной.
   - Выровняем связку "Меню + Контент" по центру (`justify-content: center`).

2. **Типографика (Стильно и понятно)**
   - Откалибруем размеры шрифтов для элегантности:
     - `h1`: `clamp(2rem, 3vw, 3rem)` — крупный, но не гигантский.
     - Основной текст: `1.05rem` с `line-height: 1.7` (воздушный, легко читаемый).
     - Заголовки секций: H2 (`1.7rem`) и H3 (`1.25rem`).
   - Подзаголовок: `1.1rem`.

3. **Вкладки (Tabs)**
   - Полностью переделаем дизайн вкладок под Segmented Control (переключатель в виде единой плашки с закругленными краями, внутри которой двигается активная кнопка).
   - Перебьем глобальные стили кнопок `!important`, чтобы они не красились в фиолетовый цвет при наведении (как на скриншоте).

4. **Оглавление (TOC)**
   - Ширина `260px`.
   - Шрифт ссылок `0.95rem` (аккуратнее, чем раньше).
   - Приглушенные цвета, активный пункт подсвечивается легким фоном `rgba(255,255,255,0.05)` и белым текстом.

5. **Блоки кода и Заметки (Callouts)**
   - Убираем агрессивные прыжки и тени при наведении. Оставляем легкое изменение цвета рамки (border), чтобы не отвлекать от чтения.
   - Закругления `8px`, шрифты внутри `0.9rem` для кода и `0.95rem` для текста заметок (чтобы они были чуть меньше основного текста).

## Шаги проверки
1. Открыть `/docs.html`.
2. Убедиться, что колонка текста имеет адекватную ширину и не растягивается на весь экран.
3. Проверить, что вкладки выглядят как аккуратный переключатель.
4. Проверить типографику — она должна быть стильной и комфортной для глаз.
