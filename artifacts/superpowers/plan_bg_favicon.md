# Суперсила: Добавление сетки-фона и нового фавикона

## 1. Brainstorm (Мозговой штурм)
**Goal (Цель):**
1. Применить стильный сетчатый фон (`.grid-bg`) и свечение (`.ambient-glow`) на все страницы системы (админка, лендинг, файловый менеджер, и т.д.).
2. Создать новый фавикон в виде изометрического куба из логотипа, где верхний ромб фиолетовый с белой буквой `m`, а средний ромб белый (или прозрачный, чтобы был виден).

**Constraints (Ограничения):**
- Сетка не должна перекрывать контент (нужно проверить `z-index` и то, что она лежит на фоне).
- Нужно обновить файл `favicon.svg` так, чтобы он корректно отображался во вкладке браузера и соответствовал логотипу по стилю.

**Risks (Риски):**
- Добавление `div.grid-bg` на страницы с другим `layout` может сломать позиционирование (так как сетка имеет `position: absolute`). Следует добавлять элементы в контейнеры, имеющие `position: relative`, или прямо в `main`. На лендинге может понадобиться дополнительный контроль.

**Acceptance Criteria (Критерии приемки):**
- На всех страницах виден фоновый узор в виде сетки.
- Фавикон изменен на логотип с буквой `m`.

## 2. Шаги реализации

### Шаг 1: Обновление `favicon.svg`
Отредактировать файл `public/favicon.svg`. Вставить туда SVG-код изометрического куба с тремя ромбами:
- Верхний ромб: фиолетовый (`#6c5ce7`).
- Средний ромб: белый (`#ffffff`).
- Нижний ромб: прозрачный с фиолетовой границей.
- На верхнем ромбе разместить плоскую белую букву "m".

### Шаг 2: Добавление фона на страницы CMS
Добавить следующие строки в начало блока `<main>` (или сразу после тега `<body>` для страниц без `main`) на страницах:
```html
<div class="grid-bg"></div>
<div class="ambient-glow"></div>
```
Страницы для обновления:
- `public/admin.html`
- `public/docs.html`
- `public/file-manager.html`
- `public/login.html`
- `public/offer.html`
- `public/privacy.html`
- `public/register.html`
- `public/settings.html`
- `public/terms.html`
- `public/visual-editor.html`

### Шаг 3: Добавление фона на лендинг
Добавить фон в `public/index.html`. Нужно проверить, где лучше его разместить: скорее всего в секции `<main>` или `<section class="land-hero">`, чтобы сетка гармонично легла на первый экран.

### Шаг 4: Развертывание (Деплой)
Запустить скрипт `.\scratch\deploy_changes.ps1` для выгрузки файлов на сервер.

## 3. Проверка (Verification)
- Открыть сайт в браузере и проверить отображение фавикона.
- Пройтись по всем страницам и убедиться, что фон-сетка корректно отображается и не ломает верстку.
