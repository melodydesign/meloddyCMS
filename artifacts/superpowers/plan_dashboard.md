# План редизайна дашборда (Premium Glassmorphism)

## 1. Brainstorm (Анализ)
- **Цель:** Полностью обновить дизайн дашборда, чтобы он соответствовал премиум-уровню страницы регистрации (стекло, плавные тени, красивые градиенты, иконки). Вернуть ширину кнопок клиентов.
- **Ограничения:** Верстка должна оставаться адаптивной, логика JavaScript (`dashboard.js`) не должна сломаться от изменения DOM-структуры (например, добавления иконок в карточки).
- **Риски:** Испортить логику кликов по карточкам сайтов или вкладкам клиентов при добавлении новых HTML-оберток. Излишнее "пересвечивание" интерфейса.
- **Критерии приемки:**
  - Карточки статистики имеют иконки, свечение, эффект стекла (`backdrop-filter`).
  - Вкладки клиентов занимают нужную ширину (используют grid или красивый скролл) и выглядят стильно.
  - Пустые стейты переоформлены.
  - На фоне дашборда добавлены "ambient orbs" (размытые световые пятна).

## 2. Шаги реализации
1. **Обновление `style.css`:**
   - Вернуть `padding: 0.6rem 1.25rem` для `.btn`.
   - Написать стили для `.stat-card-glass` (карточки статистики) с градиентными бордерами, `backdrop-filter: blur(12px)`.
   - Написать стили для фоновых орбов (`.ambient-orb`).
2. **Обновление `dashboard.html`:**
   - Добавить `<div class="ambient-orbs">...</div>` на фон.
   - Переписать HTML-разметку верхних 5 карточек: добавить внутрь красивые SVG-иконки и обернуть в новые классы.
3. **Обновление `dashboard.js`:**
   - Изменить рендер пустых состояний (вместо `<div style="...">Нет проектов</div>` сделать красивую заглушку со стилизованным стеклом и иконкой).
   - Изменить рендер контейнера `tabsContainer`. Сделаем `display: flex; flex-wrap: wrap;` или горизонтальный скролл `overflow-x: auto` с красивыми чипсами, но если клиентов мало (до 4), они будут тянуться на всю ширину `flex: 1`.
4. **Тестирование и деплой.**
   - Убедиться, что логика JS не сломана.
   - Залить файлы на сервер.
