# План исправления логики "Код доступа для разработчика"

1. **Анализ**: В файле `public/dashboard.html` (строки 392-398) поле для ввода кода разработчика сейчас заблокировано атрибутом `readonly`, а рядом находится кнопка "Сгенерировать", создающая случайный ключ. Это неправильно, так как клиент должен сам вставлять ключ, полученный от разработчика.
2. **Изменение HTML**:
   - Убрать атрибут `readonly` у поля `<input id="settDeveloperCode">`.
   - Удалить кнопку "Сгенерировать" (и обертку, если она больше не нужна), так как код не должен генерироваться на стороне клиента.
   - Сделать так, чтобы поле выглядело как обычное текстовое поле для ввода (как Chat ID или Домен).
3. **Верификация**: Открыть дашборд, перейти в настройки сайта и убедиться, что в поле можно вставить код разработчика (например, `dljVjy32`), и кнопка "Сгенерировать" больше не сбивает с толку. Нажатие на "Сохранить настройки" будет штатно сохранять введенный код.

Пожалуйста, введите команду \`/superpowers-execute-plan\`, чтобы я применил эти изменения.
