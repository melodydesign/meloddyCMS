# План: Модернизация стиля визуального редактора под Boltshift v2

Этот план описывает шаги по обновлению стилей верхней панели и боковых колонок визуального редактора для приведения его к закругленному, воздушному и премиальному стилю.

## Изменения

1. **Обновление верстки и стилей в [visual-editor.html](file:///c:/Users/9/Desktop/meloddyCMS/public/visual-editor.html):**
   - Добавить подключение `style.css?v=9` для сброса кэша.
   - Превратить кнопки выбора устройств (Монитор, Планшет, Телефон) в современный сегментированный переключатель (`.segmented-tabs`), аналогичный вкладкам на главной странице.
   - Убрать инлайновые устаревшие стили (яркий синий цвет `#0070F3` у кнопки "Опубликовать" заменить на использование нашего основного `--primary` цвета через CSS).
   - Сделать кнопки действий более закругленными (радиус `12px`) и воздушными.
   - Оформить боковые панели "Слои" и "Стили":
     - Заменить жесткие рамки на мягкие полупрозрачные границы.
     - Добавить больше внутренних отступов и скруглить плашки элементов слоев при наведении.

2. **Модификация CSS в [style.css](file:///c:/Users/9/Desktop/meloddyCMS/public/css/style.css) (при необходимости):**
   - Добавить стили для элементов редактора, чтобы они выглядели цельно с общей дизайн-системой.

## Верификация

1. **Локальная проверка**: убедиться, что разметка и классы в `visual-editor.html` написаны корректно.
2. **Деплой на сервер**: запустить `deploy.py`.
3. **Ручная проверка**: открыть визуальный редактор на meloddy-crm.ru, проверить отображение кнопок разрешений, кнопок сохранения/публикации и боковых панелей.
